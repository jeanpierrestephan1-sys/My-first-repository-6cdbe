# Turkey Bowl Pool 2026

Family pick'em: 5 NFL + 10 college games, against the spread, $1 a game.

- `public/index.html` — the whole front end
- `netlify/functions/api.mjs` — API, game list and lines (Netlify Blobs for storage)

Set the `ADMIN_CODE` environment variable in Netlify to enable the commissioner tools.
